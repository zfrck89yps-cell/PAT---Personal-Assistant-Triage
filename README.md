# PAT — Personal Assistant & Triage

A local-first personal assistant PWA built as a single dashboard for daily triage, tasks, brain dumps and ChatGPT handoff.

## V1
- Today view for due, overdue and undated tasks
- Priority and due dates
- Task completion and deletion
- Brain dump notes
- Convert a brain dump into a task
- Copy open tasks
- Prepare a structured daily-assistant prompt and open ChatGPT
- Export a local JSON backup
- Offline-capable after first load

## iPhone
Host with GitHub Pages, open in Safari, then Share > Add to Home Screen.

## Planned next

2. Email triage
3. Daily briefing
4. Research / buying / booking queue
